# World Travel

2027 세계여행을 준비하고 여행 중에도 쓰는 웹앱(PWA)이에요. 아이폰 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 지금 되는 것

- **계획**: 구글 시트/엑셀 계획표(일 · 국가 · 도시 · 내용 · 숙박 · 기타)를 복사해 붙여넣으면 Day별 일정으로 가져와요. 날짜는 출국일 기준으로 자동 계산되고, Day를 추가·삭제·이동하면 번호가 다시 매겨져요.
- **바로가기**: 계획 위쪽 대륙·나라 버튼을 누르면 그 나라 첫날로 이동해요.
- **예약**: 계획표에서 숙소(연속 숙박 묶음), 이동, 투어를 찾아 예약할 목록을 자동으로 만들어요. 예약 완료 체크, 예약한 곳·예약 번호·금액 기록, 마감일이 다가오거나 지나면 홈과 탭에 표시해요.
- **항공편**: 출발·도착 도시와 시간을 넣으면 계획의 해당 날을 찾아주고, 도착일이 다르면 앞 도시 체류를 늘리거나 줄여서(첫 항공편이면 출국일을 옮겨서) 계획을 맞춰요.
- **가계부**: 카드·현금 결제수단, 통화별 지출, 원화 환산, 환전 기록(받은 환율로 자동 반영), 현금 잔액, 카테고리별 합계. 홈에서 지금까지 쓴 돈과 남은 예산을 보여줘요.
- **지도**: 대륙 / 나라 / 도시 단위로 동선을 봐요. 이동 수단별로 선 색이 다르고 비행기는 점선이에요.
- **준비물**: 장기여행 기본 목록을 체크하고, 여행 중에 필요해진 물건을 따로 적어둬요. 산 물건은 가계부에 "필요물품 구매"로 바로 넣을 수 있어요.
- **기타**: 나라별 입국 정보(한국 여권 기준, 쉥겐 180일 중 90일 자동 계산), 중요 서류 사진·PDF 오프라인 보관, 안전카드(현지 긴급전화, 영사콜센터, 보험사, 비상연락처).
- **AI에게 물어보기**: 계획 점검, 미리 할 예약, 이동 방법 같은 질문을 내 계획표와 함께 만들어 복사해줘요. Claude, ChatGPT, Gemini 앱에 붙여넣어 쓰면 돼요 (추가 비용 없음).
- 데이터는 폰 안(IndexedDB)에 저장돼서 인터넷이 없어도 계획을 보고 고칠 수 있어요. 한 번 본 지도 타일도 저장돼요.

여행 기록(사진·메모·별점)은 다음에 만들어요. 알림은 지금은 앱 안 표시이고, 폰 푸시 알림은 배포 후 붙일 예정이에요.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # 배포용 빌드 (dist/)
SEED_TSV=계획표.tsv npm run build:artifact   # 클로드 아티팩트용 한 파일 체험판
```

기술: React + TypeScript + Vite, vite-plugin-pwa, Dexie(IndexedDB), MapLibre + OpenFreeMap 지도.
